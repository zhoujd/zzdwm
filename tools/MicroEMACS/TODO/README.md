# MicroEMACS TODO

This directory contains feature proposals and implementation notes. Runnable
samples belong in [`examples`](../examples).

- [`tag-ring.md`](tag-ring.md) — completed implementation notes for the tag
  origin ring and remaining navigation ideas.
- [`cscope-hardening.md`](cscope-hardening.md) — completed implementation notes
  for robust cscope response parsing and Unix pipe handling.
- [`legacy-platform-files.md`](legacy-platform-files.md) — completed notes for
  retaining obsolete BSD/VAX sources under `sys/legacy/`.
- [`ai-connection.md`](ai-connection.md) — proposal for a local Ollama
  connection exposed to Lisp.
- [`lisp-extensions.md`](lisp-extensions.md) — completed implementation notes
  for Lisp runtime loading, editor bridges, messaging, and floating point.
- [`script-mode.md`](script-mode.md) — completed implementation notes for
  non-interactive Lisp scripts and shebang support.
- [`dired-lisp.md`](dired-lisp.md) — completed implementation notes for the
  shell-free, Lisp-driven directory editor.
- [`smart-find-file.md`](smart-find-file.md) — completed implementation notes
  for symlink-aware Lisp file opening.
- [`path-boundaries.md`](path-boundaries.md) — completed design notes for the
  internal POSIX path format and MinGW conversion boundaries.

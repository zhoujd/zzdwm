usage
=====

## Standard Conventions

| Format | Where It's Commonly Used | Standard Context |
| :--- | :--- | :--- |
| **`Usage: ...`** | Standard CLI binaries, C/Go/Rust tools, `--help` outputs. | Formal GNU / POSIX utility standard for user documentation. |
| **`usage: ...`** | Shell scripts (`bash`, `sh`), OpenBSD / BSD tools, Python scripts. | Lightweight/casual helper outputs and error messages. |
